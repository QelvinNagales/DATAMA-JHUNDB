# JhunDB - City Library Hub

A modern library management system built by **JhunDB Database Solutions**.

## Project Overview

City Library Hub is a comprehensive library management solution featuring:
- Member management
- Book catalog and inventory
- Author tracking
- Category organization
- Loan management
- Fine tracking
- Librarian administration

## Getting Started

### Prerequisites

Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd city-library-hub

# Install dependencies
npm i

# Start the development server
npm run dev
```

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

Build for production:

```sh
npm run build
```
